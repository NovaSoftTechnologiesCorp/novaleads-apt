# NovaLeads CRM para Linux (apt)

Repositorio apt de [NovaLeads CRM](https://novaleadscrm.com) para Ubuntu 22.04+ y Debian 12+ (amd64).

```sh
curl -fsSL https://novasofttechnologiescorp.github.io/novaleads-apt/instalar.sh | sudo sh
sudo apt install novaleads
```

Las actualizaciones llegan con `sudo apt upgrade`. Lo publica el workflow `linux-deb` del repo de la app; no se edita a mano.

Clave de firma: `01EA 5667 688C 2BB6 D967 9784 8B60 A69E F6B2 9C85 ` (`novaleads.asc`).
